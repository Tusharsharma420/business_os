## 🚀 Features

- **Accounting Dashboard**: Comprehensive overview of debit/credit tracking and cash flow.
- **Inventory Management**: Distinct categorization of product and service entities.
- **Invoice Generation**: Custom invoice generation in printable formats.
- **Multi-Firm Support**: Seamlessly manage multiple business entities under a single account.
- **Offline-First Synchronization**: Robust offline capabilities with local-to-cloud synchronization.
- **Anonymous Onboarding**: Frictionless user onboarding process.

## 🛠 Tech Stack

- **Frontend**: React Native, Expo
- **Backend/DB**: Firebase Firestore
- **State Management**: Redux/Context API

## 🏁 Getting Started

### Prerequisites
- Node.js
- Expo CLI
- Firebase Account

### Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/Tusharsharma420/business_os.git
   ```
2. Navigate to the project directory:
   ```bash
   cd business_os
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the Expo server:
   ```bash
   npx expo start
   ```
