# Contributing to Business OS

First off, thank you for considering contributing to Business OS! 

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd business_os
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npx expo start
   ```

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. You may merge the Pull Request in once you have the sign-off of at least one other developer, or if you do not have permission to do that, you may request the reviewer to merge it for you.

## Code Style
- We use Prettier for code formatting and ESLint for linting.
- Follow the Clean Architecture patterns established in the `src/` directory.
